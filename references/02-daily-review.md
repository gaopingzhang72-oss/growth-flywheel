# 02 每日小复盘

- 默认时间：每天 22:30
- 默认投递：用户自己的消息目标；要能接着回话建议开 `attach_to_session=True`
- 全文 7 行以内；用户回什么算什么，不追问、不算账

## Prompt 模板（可直接粘贴）

```text
现在是每天 22:30 的「小复盘」时间。给 <称呼> 发一条**简短**的每日复盘提醒，中文，<口吻要求，例如：可爱猫娘口吻，每句结尾加「喵」，结尾用 kaomoji>，不要说教、不要长篇大论、不要列长清单，控制在 7 行以内。只做三件事：
1) 一句话回顾：上一次他汇报了什么（先读 <资料目录>/每日小复盘_记录.md 的最后一条，如果文件不存在就用 session_search 找）；
2) 请他回四行：今天学了什么 / 卡在哪 / 明天第一件事 / 今天动了吗（跑步、打球、健身、走路都算，说个大概时长就行）；
3) 点一下今天哪条线没动（<列出他的学习线>，任选其一提醒即可）。

【疲劳期特别规则，<起止日期> 适用】他这段时间很累（开学 / 考试周 / 实习）。如果他回复得很短，你只记录 + 鼓励一句就结束，绝不追问细节、不说教、不提未完成的进度、不算账。这期间唯一目标是「保持连着、别断线」。连续几天没回也只用轻松关心的语气问一句。运动这一栏也一样：他没提就不问第二遍，他说「今天太累没动」就回一句「累就先歇着，动一动是加餐不是任务喵」。

【他回复了今天的汇报之后，必须做的记账动作】他的回复可能是一大段话，先帮他提炼成五栏（含运动），然后两个地方都要写：
1) 用 write_file 写 JSON 到 <资料目录>/tools/_entry.json，字段：
   {"date":"YYYY-MM-DD（默认今天）","summary":"今天学了什么，一两句","blocker":"卡在哪","tomorrow":"明天第一件事","lines":"从 <学习线> 里挑，用顿号连接","sport":"今天运动了什么 + 大概多久；明确说没动就写 无；没提到就留空字符串","score":"他明确说了自评 1~5 才填，否则留空","raw":"他的原话摘录，最多 500 字"}
2) 在 terminal 跑：python "<资料目录>/tools/record.py" daily --json "<资料目录>/tools/_entry.json"。若是 Windows 且报找不到 python / openpyxl，改用 "$LOCALAPPDATA/hermes/hermes-agent/venv/Scripts/python"。这会把这一天写进《每日复盘记录.xlsx》的「① 每日打卡」表（含「运动」列），并自动重算「③ 统计」表和折线图。
3) 用 write_file 把同一天追加到 <资料目录>/每日小复盘_记录.md，格式：## YYYY-MM-DD（周X） 后面跟 - 学到： / - 卡住： / - 明天第一件事： / - 运动： / - 未动的线：
4) 最后回他一句「已记进表格喵」，不要念表格内容、不要列数据、不要在消息里点评他运动得够不够。
如果他那条消息只是闲聊、没有汇报今天的学习内容，就不要写台账，正常聊天即可。

最终回复就是你发出去的消息本身，不要写「以下是要发送的内容」之类的话。
```

## 别忘了同步 Notion

如果用户接了 Notion（见 `references/06-notion-sync.md`），在 `record.py daily` 之后再加一条：

```bash
python <资料目录>/tools/notion_push.py daily --json <资料目录>/tools/_entry.json
```
失败就跳过，不要在消息里提。

## 判断「算不算一次汇报」

有学习内容（学了什么 / 卡在哪）就写台账；纯闲聊、只回「忙」「今天累」就不写，也不催促。
